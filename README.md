# 智能引用 (smart_quote)

只在**需要**的时候引用回复：当被回复的那条消息已经不是会话里最新的一条时，自动在回复里补上引用；回最新消息则不加引用，避免满屏引用。

## 原理

- 插件记录每个会话最后一次收到消息的时间
- 发送前比较：如果期间有新消息进来，或者这条消息已经等了超过阈值秒数 → 插入引用
- 已有引用时不重复添加

## 安装

把本仓库放进 AstrBot 的 `data/plugins/` 目录，重启 AstrBot 即可。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enable` | true | 总开关 |
| `group_only` | true | 只对群聊生效 |
| `quote_after_seconds` | 6 | 等待超过多少秒就补引用 |

适用于 AstrBot >= 4.0.0。
